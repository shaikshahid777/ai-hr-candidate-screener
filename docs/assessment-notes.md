# Assessment Notes

## Challenges

The main validation challenge was ensuring that each rule could be demonstrated independently without an unintended rule taking precedence.

## Resolution

Dedicated resumes and open-position documents were created for the missing-contact, weak-data, certification, and multiple-options scenarios.

## Assumptions

The uploaded job descriptions and candidate resumes are treated as the authoritative sources for each screening test.

## Limitations

The screener only evaluates information present in the supplied documents. It does not independently verify candidate claims or retrieve external candidate information.
